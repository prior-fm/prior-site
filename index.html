Start with examples.

During training, the model sees digit images paired with the correct answers. Each image becomes a grid of numbers describing its pixels.

Learn from mistakes.

The network combines those numbers through weighted connections. Training adjusts the connection strengths to reduce mistakes on the examples.

Try an unseen image.

The trained network uses those connections to predict the digit in a new image. Its answer can be wrong; unseen examples help us test how well it learned.
