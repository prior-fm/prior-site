The watermark
is in the
choosing

No hidden characters, no invisible spaces — the mark is in which word got picked

At almost every word, a model has several choices that would all work equally well. Normally which one comes out is decided by an arbitrary random number. A text watermark swaps that source for a secret key — so the sequence of picks carries a pattern only someone with the key can test for. The file is exactly as long as it would have been, and every word was one the model would have said anyway.

Two things people get wrong
Not nudged.
Not lost in
translation.

Anthropic's own write-up on Claude's text watermark says the key changes the source of the randomness used to choose between candidates — not the odds themselves. Claude is not pushed toward odd or unusual words, and there is no fixed list of "AI words" to bias toward. The green-list / red-list diagram in wide circulation describes a different, published academic scheme (KGW) that does bias the model's choices — useful to know, but not a description of Claude's. And translation does not launder the mark: the translation is written by the model too, one chosen word at a time, so the pattern is right back in it.
