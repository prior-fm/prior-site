No. 017 · Architecture
Not a
Transformer.
A brain.

A Transformer stops learning the moment training ends. This one never stops.

Just under two minutes on BDH — the Dragon Hatchling — an architecture built out of neurons and synapses rather than layers and attention heads. Every number on screen comes from an actual run of the network the film describes: 512 neurons, 12,230 synapses, no training phase at all. Five invariants are checked on every execution, and the film would not have been built if any of them had failed.

What it is
Four stages,
one loop.

There is no attention block and no backward pass. There is a sparse, non‑negative graph of 512 neurons joined by 12,230 synapses — 4.67% of the connections that could exist, a mean of 23.9 each — and every step does four things in order.

Propagate. Belief flows forward along weighted implications. Because no weight is ever negative, belief can only be added, never cancelled — the network cannot argue itself out of something it already holds. Strengthen. Connections that just fired together get stronger. Compete. Excitation and inhibition fight, and only strong signals clear the threshold. Feed back. The survivors are the next step’s input.

That is the whole machine. 4.41% of neurons fire on an average step, and that sparsity is not assumed — it is caused. Run the same network with competition removed and 99.2% of it lights up at once, carrying nothing.

The thing worth noticing
It learns
while it
thinks.

The network in the film is shown twelve pairs of symbols, six times over. Then each cue is shown alone, and the question is whether anything comes back.

Recall comes out at 38%, against a chance baseline of 4.9%. Nothing was trained to do that. The fixed synaptic graph — the wiring the network started with — scores 4.0% on the same readout, which is chance. The association is not in the wiring.

It is in the synapses, which changed during inference. Their total strength goes from exactly zero at the start of the run to 233.3 by the end, and the run is the only thing that put it there. That is what “it keeps learning while it thinks” has to mean if it is going to be worth saying: a quantity that was zero, is not zero, and is doing the work.

How the numbers were made
One run,
five gates.

Nothing on screen is a plausible-looking figure. One script builds the graph, runs the sequence, and refuses to print GO unless five invariants hold — each one chosen because a wrong formulation would fail it.

The strongest is the equivalence check. The same run is computed twice: once as explicit message passing along every one of the 12,230 edges with a full 512×512 matrix of fast weights, and once as two small matrix–vector products with those fast weights held as a linear‑attention state that is never built at all — the form the architecture uses to run on a GPU. The two agree to 7.8×10−16, machine precision. A transpose, an index slip, or a decay applied one step out of order all fail it. They are the same machine, and the sparse brain-shaped picture and the dense GPU-shaped one are two views of it.

The rest: activity must stay sparse because of inhibition and not by assumption, measured against a control with inhibition removed; every positive-weight edge carrying belief must contribute strictly positively, checked on every edge on every step; the strengthening must happen on exactly the pairs that fired together and nowhere else; and recall must beat chance from the fast weights while sitting at chance from the graph alone.

One honest limit. This is 512 neurons on an associative-recall task, not a language model. It demonstrates the mechanism — the loop, the sparsity, the learning during inference, the equivalence of the two forms — and it says nothing about how the architecture behaves at scale. That claim belongs to people with a cluster.

The pack — free, no email
The whole
model,
one file

Not a re-implementation of the film. The same script, with its output path moved.

bdh.py — Python 3.8+ and numpy, nothing else, no network. It is the script that produced every number above, shipped as it ran. Deterministic: fixed seed, no wall clock. Run it and you get 512 neurons, 12,230 synapses, 4.41% active, 38% recall — to the digit, in about twenty seconds.

Then break it on purpose. BDH_THETA=0 removes inhibition and the network still runs, still propagates, still writes to its synapses — and stops working, because 99.2% of neurons firing at once carries nothing to recall. BDH_ETA=0 removes the learning rule and recall falls from 38% to 8%. BDH_LAM=0.90 makes it forget faster and recall drops to 23%. Each of those is a run, not a prediction.

Where this actually turns up

Every model you use in production is frozen. It knows what it knew when the training run stopped, and everything since arrives as context you have to keep re-feeding it — which is why the whole industry is building retrieval systems, longer windows and memory layers on the outside of models that cannot remember. An architecture that changes its own weights while it runs is an argument that the memory belongs on the inside.

Whether it holds at scale is an open question. Whether the mechanism works at all is not: run the file and watch zero become 233 →
