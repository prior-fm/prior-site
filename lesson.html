The idea in one page

A model can learn a line from examples.

We will use a simple line, answer = slope × input + offset. Training changes the slope and offset until the line is close to the examples. Testing uses separate examples to check whether the pattern carries across.

The line has two learned values: its slope and its offset. The learning rate controls how far each update moves the values. The error figures average the squared gaps between predictions and answers: smaller is better. They use the displayed answers, squared.

A useful trap

What if one example misleads it?

Change the final answer so it contradicts the original pattern, then retrain and compare the result. A model learns the data it receives, including data that does not belong.
