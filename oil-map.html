What you can change

  • Route coordinates and their visual paths.
  • Camera positions, scale and reveal timing.
  • Map typography, borders and colour tokens.

The download includes the local geography, map assets, source code and editing notes.

Open it locally

  1. Download and extract the ZIP.
  2. Open the included README.md and follow its Studio instructions.
  3. Edit the files in data/, then run npm run build to rebuild the map.

You’ll need Node.js and HyperFrames. No paid media or font subscription is required for this map package.

This is a schematic editorial reconstruction, not navigation data. Routes and camera framing are approximate. The package does not include the original film, narration, music, or current-event and export claims. Geography and dependency credits are included in the download.
